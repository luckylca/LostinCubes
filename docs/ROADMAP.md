# Roadmap

## Milestone 0 — Foundation

Initialize Vite/Babylon.js, strict TypeScript, lint/format/test commands, CI, GitHub Pages deployment, prototype scene, and core documents.

## Milestone 1 — Player and cameras

Add fixed-step simulation, kinematic movement, gravity, jump, block collision, first/third-person cameras, switching, desktop input, touch movement/camera, pause, and settings.

## Milestone 2 — Voxel world

Add deterministic seeds, chunk storage, generation, streaming, meshing, atlas materials, block raycasts, mining/placing, worker processing, and quality-based view distance.

## Milestone 3 — Inventory and crafting

Add item data, drops, pickup, hotbar, inventory, tools, block items, recipes, harvesting speed, and usable UI on desktop/mobile.

## Milestone 4 — Combat

Add player combat state machine, stamina, attacks, dodge, blocking, target lock, damage, death/revival, recovery resource, three enemies, and AI state machines.

## Milestone 5 — Story and boss

Add guide character, quests, rune slabs, ruins, protected boss gate, two-phase boss, reward, chapter conclusion, and next-fragment hook.

## Milestone 6 — Saves

Complete IndexedDB slots, auto/manual save, import/export/delete, validation, migrations, world edits, quests, enemies, boss, checkpoint, and recovery-point persistence.

## Milestone 7 — Performance and release

Profile, pool objects, budget chunk work, reduce allocations, finalize quality levels/dynamic resolution, harden mobile UI, add loading/error handling, publish Pages, and test the full chapter.
